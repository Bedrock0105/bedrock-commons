# 动态数据源

## 概述

`bedrock-common-dynamic` 基于 **baomidou dynamic-datasource** 提供 Bedrock 增强层，支持：

- `@DS` 注解切换数据源
- 运行时动态加载数据源（`DataSourceDynamicLoad`）
- 启动时从数据库加载数据源列表（`DataSourceStartLoad`）

> **bedrock-cloud 当前未使用本模块**，采用单数据源配置。本文档描述模块能力，供需要多数据源的项目参考。

---

## 快速开始

### 1. 引入依赖

```xml
<dependency>
    <groupId>org.bedrock</groupId>
    <artifactId>bedrock-common-dynamic</artifactId>
</dependency>
```

### 2. 配置

```yaml
spring:
  datasource:
    dynamic:
      primary: master
      strict: false
      lazy: true
      aop:
        enabled: true
      datasource:
        master:
          url: jdbc:mysql://localhost:3306/bedrock
          username: root
          password: root
          driver-class-name: com.mysql.cj.jdbc.Driver
        slave:
          url: jdbc:mysql://localhost:3306/bedrock_slave
          username: root
          password: root
          driver-class-name: com.mysql.cj.jdbc.Driver
```

也支持 Spring 标准单数据源配置，框架自动回填到 `primary` 数据源：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/bedrock
    username: root
    password: root
```

### 3. 切换数据源

```java
@DS("slave")
public List<User> listFromSlave() {
    return userMapper.selectList(null);
}
```

## Bedrock 扩展点

### DataSourceDynamicLoad（运行时加载）

```java
@Component
public class MyDataSourceLoad implements DataSourceDynamicLoad {
    @Override
    public DataSource load(String dsKey) {
        // 根据 dsKey 动态创建并返回 DataSource
    }
    @Override
    public int getOrder() {
        return 0;
    }
}
```

通过 `DataSourceDynamicLoadSupport` 操作：

```java
DataSourceDynamicLoadSupport.load("dsKey");   // 加载
DataSourceDynamicLoadSupport.add("dsKey", ds); // 添加
DataSourceDynamicLoadSupport.remove("dsKey");  // 移除
DataSourceDynamicLoadSupport.isExist("dsKey"); // 是否存在
```

### DataSourceStartLoad（启动时加载）

```java
@Component
public class MyDataSourceStartLoad implements DataSourceStartLoad {
    @Override
    public Map<String, DataSourceProperty> load() {
        // 从数据库读取数据源配置列表
    }
}
```

`DefaultAbstractJdbcDataSourceProvider` 在启动时连接主库，执行 `DataSourceStartLoad` 加载额外数据源。

---

## 注意事项

1. `@DS` 注解来自 baomidou 库（`com.baomidou.dynamic.datasource.annotation.DS`）
2. `@DS` 应在 `@Transactional` **之前**生效（AOP 顺序）
3. 同类内部调用不触发 AOP，需通过代理调用
4. bedrock-cloud 使用单数据源，未引入本模块
