# 测试模块 (Test)

## 概述

`bedrock-common-test` 提供 Bedrock 项目的测试注解和扩展，简化 Spring Boot 集成测试。

---

## @BedrockTest

组合 `@SpringBootTest` + `@ExtendWith(BedrockSpringExtension.class)`：

```java
@BedrockTest(appName = "bedrock-system", profile = "dev")
class AdminServiceTest {

    @Autowired
    private IAdminService adminService;

    @Test
    void testDetail() {
        AdminDetailVO detail = adminService.detail(1L);
        assertNotNull(detail);
    }
}
```

### 属性

| 属性 | 默认值 | 说明 |
|------|--------|------|
| `appName` | `bedrock-test` | 应用名称 |
| `profile` | `dev` | 环境 Profile |
| `enableStartConfiguration` | `false` | 是否启用 StartConfiguration SPI |
| `properties` | `[]` | 额外配置属性 |
| `args` | `[]` | 启动参数 |
| `classes` | `[]` | 指定配置类 |
| `webEnvironment` | `MOCK` | Web 环境类型 |

---

## BedrockSpringExtension

JUnit 5 扩展，在测试启动前设置 `spring.application.name` 和 `spring.profiles.active`。

---

## 注意事项

1. 集成测试需配置测试数据库和 Redis 连接
2. 默认 `webEnvironment=MOCK`，不需要真实 Web 容器
3. bedrock-cloud 项目目前测试用例较少，可按需补充
