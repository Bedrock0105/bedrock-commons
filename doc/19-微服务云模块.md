# 微服务云模块 (Cloud)

## 概述

`bedrock-common-cloud` 是微服务项目的**薄封装**，提供：

- `@BedrockCloudApplication` 组合启动注解
- Feign 请求头自动转发
- Sentinel Feign 熔断增强

> 本模块**不包含** Nacos 注册/配置、Gateway 路由、链路追踪等完整云原生能力，这些依赖 Spring Cloud 生态或 `bedrock-gateway` 工程。

---

## 快速开始

### 1. 引入依赖

```xml
<dependency>
    <groupId>org.bedrock</groupId>
    <artifactId>bedrock-common-cloud</artifactId>
</dependency>
```

### 2. 启动类

```java
@BedrockCloudApplication
public class SystemApplication {
    public static void main(String[] args) {
        BedrockApplication.run(ApplicationConstant.APPLICATION_SYSTEM_NAME, SystemApplication.class, args);
    }
}
```

`@BedrockCloudApplication` 等价于：

```java
@SpringBootApplication
@EnableDiscoveryClient
@EnableFeignClients("org.bedrock.**.feign.**")
```

### 3. 定义 Feign 客户端

放在 `org.bedrock.**.feign.**` 包下：

```java
@FeignClient(name = "bedrock-system")
public interface IAdminClient {
    @GetMapping("/feign/admin/detail")
    R<AdminDetailVO> detail(@RequestParam("id") Long id);
}
```

## Feign 请求头转发

`DefaultFeignRequestInterceptor` 从 ThreadLocal 中读取已收集的 HTTP 请求头，原样转发到 Feign 请求。

请求头收集由 boot 模块 `RequestListener` 完成，需在配置中指定需要转发的头：

```yaml
bedrock:
  content:
    headers:
      - Authorization
      - X-Tenant-Id
      - X-User-Account-Id
```

默认 `headers` 列表为空，**需手动配置**才能传递 Token 和租户信息。

---

## Sentinel 熔断

```yaml
feign:
  sentinel:
    enabled: true   # 开启 Sentinel Feign 增强
```

`SentinelInvocationHandler` 行为：

- 无 fallback 配置时，返回类型为 `R` 的接口自动返回 `R.error()`
- 其他返回类型使用默认降级逻辑

bedrock-cloud 当前 Feign 接口均未配置 fallback。

## bedrock-cloud 服务与 Feign

| 服务 | 启动类 | Feign 客户端示例 |
|------|--------|-----------------|
| bedrock-system | `SystemApplication` | — |
| bedrock-auth | `AuthApplication` | `IAdminClient` |
| bedrock-log | `LogApplication` | — |
| bedrock-resource | `ResourceApplication` | — |
| bedrock-websocket | `WebsocketApplication` | `IWebSocketClient` |
| bedrock-gateway | 独立 | 不使用 @BedrockCloudApplication |

API 模块（`bedrock-api`）定义 Feign 接口，业务模块实现 Feign 端点（`@RestController` + `@Hidden`）。

---

## Nacos 配置

Nacos 注册/配置由 Spring Cloud Alibaba 提供，`BedrockApplication` 启动时自动设置：

- 共享配置：`application-{profile}.yml`
- 服务配置：`{applicationName}.yml`

具体连接信息在各服务 `bootstrap.yml` 和 Nacos 配置中心管理。

---

## 注意事项

1. 熔断降级基于 **Alibaba Sentinel**（非 Resilience4j）
2. Feign 扫描路径固定为 `org.bedrock.**.feign.**`
3. 网关（bedrock-gateway）不使用 `@BedrockCloudApplication`，单独配置路由和鉴权
4. 本模块无独立 `bedrock.cloud.*` 配置类
