# 安全模块 (Security)

## 概述

`bedrock-common-security` 提供两类安全能力：

1. **登录拦截**：`SecurityInterceptor` 校验是否已登录（`bedrock.security.enabled=true` 时生效）
2. **接口权限**：`@PrePermissionCheck` 注解 + SpEL 表达式校验角色/权限

> 本模块**不包含**加密、脱敏、XSS、CSRF、SQL 注入防护等功能。

---

## 快速开始

### 接口权限校验

```java
// 方法级
@PrePermissionCheck("hasAnyRole('" + RoleAliasConstant.ROLE_ADMIN + "','" + RoleAliasConstant.ROLE_ADMINISTRATOR + "')")
public R<Void> resetPassword(String ids, String newPassword) { ... }

// 类级（整个 Controller 生效）
@PrePermissionCheck("hasRole('" + RoleAliasConstant.ROLE_ADMINISTRATOR + "')")
public class TenantPackageController { ... }
```

---

## @PrePermissionCheck

| 属性 | 说明 |
|------|------|
| `value` | SpEL 表达式（必填），返回 true 则放行 |

### SpEL 内置方法（SecurityExpressionExpressionRoot）

| 方法 | 说明 |
|------|------|
| `hasPermission()` | 校验当前接口权限 |
| `hasPermission("perm:code")` | 校验指定权限码 |
| `hasAnyPermission("p1", "p2")` | 任一权限 |
| `hasRole("ADMIN")` | 校验角色别名 |
| `hasAnyRole("ADMIN", "USER")` | 任一角色 |
| `permitAll()` | 放行 |
| `denyAll()` | 拒绝 |

### 引用 Spring Bean

```java
@PrePermissionCheck("@userService.isOwner(#userId)")
public R<Void> update(Long userId) { ... }
```

非 Web 环境（无 HTTP 请求）时**自动跳过**权限校验。

---

## 配置

```yaml
bedrock:
  security:
    enabled: false           # 登录拦截开关，默认关闭
    ignore-urls:             # 登录拦截白名单
      - /doc.html
      - /webjars/**
      - /v3/api-docs/**
```

---

## 权限查询逻辑

`SecurityExpressionExpressionRoot` 通过 `JdbcClient` 查询：

- `bedrock_role_permission` + `bedrock_permission_api` 表
- 缓存 key：`api:permission:role:id:{roleId}`

依赖 `bedrock-common-auth` 的 `AuthUtil` 获取当前用户角色。

---

## 异常处理

| 异常 | HTTP 状态 | 返回 |
|------|-----------|------|
| `NotLoginException` | 401 | `R.error(401, "未登录")` |
| `PermissionDeniedException` | 403 | `R.error(403, "权限不足")` |

由 `SecurityExceptionHandler` 统一处理。

## bedrock-cloud 使用位置

| Controller | 注解 |
|------------|------|
| `AdminController` | 重置密码接口 `hasAnyRole(ADMIN, ADMINISTRATOR)` |
| `TenantController` | 类级 `hasRole(ADMINISTRATOR)` |
| `TenantPackageController` | 类级 `hasRole(ADMINISTRATOR)` |
| `MenuController` | 部分接口权限校验 |

---

## 与网关的关系

- **网关**（`AuthorizeFilter`）：校验 JWT Token 有效性
- **服务内**（`SecurityInterceptor`）：校验是否已登录（可选）
- **接口级**（`@PrePermissionCheck`）：校验角色/权限

三层可叠加使用，网关鉴权 + 服务内细粒度权限控制。

---

## 注意事项

1. 默认 `bedrock.security.enabled=false`，仅 `@PrePermissionCheck` 生效
2. 权限数据来自数据库，需在 `bedrock_permission_api` 和 `bedrock_role_permission` 中配置
3. 管理员（`AuthUtil.isAdmin()` / `isAdministrator()`）在数据权限模块中自动跳过，接口权限需显式配置
