# 资源管理 (Resource)

## 概述

`bedrock-common-resource` 提供文件存储（OSS）、邮件发送、短信发送三大能力的统一抽象和工厂模式实现。

---

## OSS 文件存储

### 支持的服务商（OssEnum）

| 枚举值 | 实现类 | 说明 |
|--------|--------|------|
| `LOCAL` | `LocalOssTemplate` | 本地磁盘存储 |
| `MINIO` | `S3OssTemplate` | MinIO（S3 兼容，PathStyle） |
| `AWS` | `S3OssTemplate` | Amazon S3 |
| `ALIYUN` | `AliyunOssTemplate` | 阿里云 OSS |
| `TENCENT` | `TencentCosOssTemplate` | 腾讯云 COS |
| `HUAWEI` | `HuaweiObsOssTemplate` | 华为云 OBS |

通过 `OssBeanFactory.getOssTemplate(OssEnum, OssProperties)` 按配置动态创建实例。

### 核心接口

| 类 | 说明 |
|----|------|
| `OssTemplate` | 文件上传/下载/删除操作接口 |
| `OssFactoryBean` | OSS 实例工厂 |
| `OssProperties` | OSS 配置模型 |
| `OssResultFile` | 上传返回结果 |

### OssProperties 配置字段

| 字段 | 说明 |
|------|------|
| `endpoint` | 服务端点（本地存储时为磁盘路径） |
| `accessKey` | 访问密钥 ID |
| `secretKey` | 访问密钥 |
| `bucketName` | 存储桶名称 |
| `bucketRegion` | 区域（AWS/Tencent 必填） |
| `prefixPath` | 文件路径前缀，默认 `upload` |
| `publicUrl` | 公开访问 URL，默认使用 endpoint |

### 各服务商配置示例

**本地存储**
```yaml
endpoint: D:/bedrock/upload
bucketName: default
publicUrl: http://localhost:8080/files
```

**MinIO**
```yaml
endpoint: http://127.0.0.1:9000
accessKey: minioadmin
secretKey: minioadmin
bucketName: bedrock
publicUrl: http://127.0.0.1:9000
```

**阿里云 OSS**
```yaml
endpoint: https://oss-cn-beijing.aliyuncs.com
accessKey: your-access-key-id
secretKey: your-access-key-secret
bucketName: your-bucket
publicUrl: https://your-bucket.oss-cn-beijing.aliyuncs.com
```

**腾讯云 COS**
```yaml
bucketRegion: ap-guangzhou
accessKey: your-secret-id
secretKey: your-secret-key
bucketName: your-bucket-1250000000
publicUrl: https://your-bucket-1250000000.cos.ap-guangzhou.myqcloud.com
```

**AWS S3**
```yaml
bucketRegion: us-east-1
accessKey: your-access-key-id
secretKey: your-secret-access-key
bucketName: your-bucket
publicUrl: https://your-bucket.s3.amazonaws.com
```

**华为云 OBS**
```yaml
endpoint: https://obs.cn-north-4.myhuaweicloud.com
accessKey: your-access-key
secretKey: your-secret-key
bucketName: your-bucket
publicUrl: https://your-bucket.obs.cn-north-4.myhuaweicloud.com
```

### bedrock-cloud 用法

`bedrock-resource` 服务的 `OssSupport` 根据租户和配置码动态获取 `OssTemplate`：

```java
OssTemplate template = ossSupport.ossTemplate(tenantId, configCode);
OssResultFile result = template.uploadFile(fileName, inputStream, contentType);
```

OSS 配置存储在数据库 `bedrock_oss_config` 表，`service_provider` 字段对应 `OssEnum` 值。

## 注意事项

1. OSS 配置在 bedrock-cloud 中存储于数据库，非 YAML 静态配置
2. MinIO 使用 PathStyle 访问，AWS 使用 VirtualHost 风格
3. 腾讯云 COS 必须配置 `bucketRegion`
4. 上传文件自动按日期分目录，文件名 UUID 重命名
