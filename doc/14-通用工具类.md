# 通用工具类

## 概述

`bedrock-common-code/util` 包提供 36 个工具类，以及统一响应 `R<T>` 和启动器 `BedrockApplication`。

---

## R\<T\> 统一响应

包路径：`org.bedrock.common.code.api.R`

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | int | 状态码 |
| `msg` | String | 消息 |
| `data` | T | 数据 |
| `timestamp` | long | 毫秒时间戳 |

### 工厂方法

```java
R.success()              // 成功，无数据，code=200
R.success(data)          // 成功，带数据
R.ok(data)               // 成功，code=CommonResultCode.SUCCESS
R.status(boolean)        // 根据布尔值返回 success/failure
R.failure()              // 失败，code=400
R.failure(code, msg)     // 自定义失败
R.error()                // 错误，code=500
R.error(code, msg)       // 自定义错误
```

`CommonResultCode`：`SUCCESS(200)`、`FAILURE(400)`、`ERROR(500)`

### 加解密

密钥统一使用 Hex 字符串；密文支持 `byte[]` / Base64 / Hex 互转。对称算法默认 ECB，`*Iv*` 方法为 CBC（加密时随机 IV 拼到密文前，解密自动拆分）。

| 类 | 主要方法 |
|----|----------|
| `AesUtil` | AES：`generateKeyHex`、`encrypt`/`decrypt`、`encryptIv`/`decryptIv`（默认 128 位） |
| `DesUtil` | DES：接口同 AesUtil（默认 56 位；新系统建议优先 AES） |
| `Sm4Util` | 国密 SM4：接口同 AesUtil（固定 128 位，依赖 BouncyCastle） |
| `RsaUtil` | RSA：`generateKeyPair`、公钥加密/私钥解密、`sign`/`verify`（默认 2048，SHA256withRSA，自动分块） |
| `Sm2Util` | 国密 SM2：`generateKeyPair`、公钥加密/私钥解密、`sign`/`verify`（曲线 sm2p256v1，SM3withSM2） |

## 注意事项

1. 工具类均为静态方法，不可实例化
2. `StringUtil` 继承 Spring `StringUtils`，包含其所有方法
3. `CollectionUtil` 仅提供 `isEmpty`/`isNotEmpty`，无 `toMap`/`filter` 等集合操作
4. 统一响应使用 `R.success()`，字段名为 `msg`（非 `message`）
5. 国密工具（`Sm2Util`/`Sm3Util`/`Sm4Util`）依赖 BouncyCastle，首次调用时自动注册 BC Provider
6. `DesUtil` 密钥强度较弱，新系统优先使用 `AesUtil` 或 `Sm4Util`
7. HTTP 接口加解密见 [API 加解密文档](./24-API加解密.md)
