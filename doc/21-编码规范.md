# 编码规范

## 📖 概述

本文档定义了Bedrock Commons框架的编码规范和最佳实践，旨在提高代码质量、可读性和可维护性。所有参与项目开发的人员都应遵循这些规范。

**核心原则**:
- ✅ 清晰优于简洁
- ✅ 一致性强于个性
- ✅ 显式优于隐式
- ✅ 安全优于便利
- ✅ 性能与可维护性平衡

---

## Bedrock 项目约定

以下为 bedrock-cloud 项目的实际约定，开发时需遵循：

### 包结构

```
org.bedrock.{module}
├── controller/     # 控制器，继承 BaseController
├── service/        # 服务接口 I{Xxx}Service
├── service/impl/   # 服务实现，继承 BaseServiceImpl
├── mapper/         # MyBatis Mapper
├── entity/         # 实体，继承 BaseEntity / TenantEntity
├── param/          # 请求参数
├── vo/             # 视图对象
├── excel/          # Excel 导入导出模型
└── feign/          # Feign 客户端（api 模块）
```

### 统一响应

使用 `org.bedrock.common.code.api.R<T>`，字段为 `code`、`msg`、`data`：

```java
return R.success(data);       // 查询成功
return R.status(boolean);     // 增删改操作
return R.error(403, "权限不足"); // 错误
```

### 分页参数

使用 `Query` 对象，字段为 `current` 和 `size`（非 pageNum/pageSize）：

```java
public R<IPage<AdminListVO>> page(Query query, AdminPageParam param) {
    return R.success(service.pageAdmin(PageUtil.getPage(query), param));
}
```

### 实体基类

- 普通实体继承 `BaseEntity`（含 id、createTime、isDeleted 等）
- 多租户实体继承 `TenantEntity`（额外含 tenantId）
- 逻辑删除字段为 `is_deleted`

### 权限注解

使用 `@PrePermissionCheck`（非 `@PreAuthorize`）：

```java
@PrePermissionCheck("hasRole('" + RoleAliasConstant.ROLE_ADMIN + "')")
```

### 操作日志

在 Controller 方法上标注 `@OperationLog`，Service 层用 `LogRecordContext.putVariable()` 补充变量。

## 📝 命名规范

### 1. 类命名

```java
// ✅ 正确：使用名词，大驼峰命名
public class UserService { }
public class OrderController { }
public class UserRepository { }

// ❌ 错误：使用动词或小写
public class getUser { }
public class order_controller { }
```

**命名规则**:
- **Controller**: `XxxController`
- **Service**: `XxxService` / `XxxServiceImpl`
- **Repository/Mapper**: `XxxMapper` / `XxxRepository`
- **Entity/Model**: `Xxx` (业务名称)
- **DTO**: `XxxDTO` / `XxxRequest` / `XxxResponse`
- **VO**: `XxxVO`
- **Enum**: `XxxEnum`
- **Exception**: `XxxException`
- **Config**: `XxxConfiguration`
- **Util**: `XxxUtil`

### 2. 方法命名

```java
// ✅ 正确：动词+名词，小驼峰命名
public User getUserById(Long id) { }
public void createUser(User user) { }
public boolean isValidEmail(String email) { }

// ❌ 错误：名词开头或含义不清
public User user(Long id) { }
public void userCreate(User user) { }
public boolean email(String email) { }
```

**常用动词**:
- **查询**: get/find/query/list/search
- **新增**: create/add/insert/save
- **修改**: update/modify/edit
- **删除**: delete/remove
- **验证**: validate/check/verify/is
- **转换**: convert/transform/to
- **计算**: calculate/compute/count

### 3. 变量命名

```java
// ✅ 正确：语义清晰
private Long userId;
private String userName;
private List<Order> orderList;
private Map<String, User> userMap;

// ❌ 错误：缩写或无意义
private Long uid;
private String n;
private List<Order> list;
private Map<String, User> map;
```

**特殊变量**:
```java
// 布尔变量使用is/has/can前缀
private boolean isEnabled;
private boolean hasPermission;
private boolean canAccess;

// 常量全大写，下划线分隔
public static final int MAX_RETRY_COUNT = 3;
public static final String DEFAULT_CHARSET = "UTF-8";

// 临时变量可以简短但要有意义
for (int i = 0; i < size; i++) { }
User user = userList.get(i);
```

### 4. 包命名

```java
// ✅ 正确：全小写，点号分隔
package org.bedrock.common.auth.config;
package org.bedrock.common.user.service.impl;

// ❌ 错误：包含大写或下划线
package org.bedrock.common.Auth.Config;
package org.bedrock.common.user_service;
```

## 💻 代码格式

### 1. 缩进与空格

```java
// ✅ 正确：4空格缩进
public class UserService {
    
    public User getUser(Long id) {
        if (id == null) {
            return null;
        }
        return userMapper.selectById(id);
    }
}

// 运算符两侧加空格
int result = a + b;
boolean flag = (x > 0) && (y < 10);

// 逗号后加空格
List<String> list = Arrays.asList("a", "b", "c");
```

### 2. 大括号位置

```java
// ✅ 正确：K&R风格
public class UserService {
    
    public void method() {
        if (condition) {
            // do something
        } else {
            // do other
        }
    }
}

// ❌ 错误：Allman风格
public class UserService
{
    public void method()
    {
        if (condition)
        {
        }
    }
}
```

### 3. 行长度限制

```java
// ✅ 正确：单行不超过120字符
String message = "This is a very long message that should be " +
                 "split into multiple lines for better readability.";

// 方法参数过多时换行
public void createUser(
        String username,
        String password,
        String email,
        Integer age,
        GenderEnum gender) {
    // ...
}
```

### 4. 空行使用

```java
public class UserService {
    
    // 字段之间不加空行
    private UserMapper userMapper;
    private PasswordEncoder passwordEncoder;
    
    // 方法之间加一个空行
    public User getUser(Long id) {
        return userMapper.selectById(id);
    }
    
    // 逻辑块之间加空行
    public void createUser(UserDTO userDTO) {
        // 参数校验
        validateUser(userDTO);
        
        // 密码加密
        String encodedPassword = passwordEncoder.encode(userDTO.getPassword());
        
        // 保存用户
        User user = convertToEntity(userDTO);
        user.setPassword(encodedPassword);
        userMapper.insert(user);
    }
}
```

## 🔒 安全规范

### 1. 输入验证

```java
// ✅ 正确：严格验证输入
public void createUser(@Validated @RequestBody UserDTO userDTO) {
    // JSR-303注解验证
}

@Data
public class UserDTO {
    @NotBlank(message = "用户名不能为空")
    @Size(min = 3, max = 20, message = "用户名长度必须在3-20之间")
    private String username;
    
    @NotBlank(message = "邮箱不能为空")
    @Email(message = "邮箱格式不正确")
    private String email;
    
    @Min(value = 1, message = "年龄必须大于0")
    @Max(value = 150, message = "年龄不能超过150")
    private Integer age;
}

// ❌ 错误：未验证输入
public void createUser(UserDTO userDTO) {
    // 直接使用，可能导致安全问题
}
```

### 2. SQL注入防护

```java
// ✅ 正确：使用预编译语句
@Select("SELECT * FROM users WHERE username = #{username}")
User findByUsername(@Param("username") String username);

// ❌ 错误：字符串拼接（SQL注入风险）
@Select("SELECT * FROM users WHERE username = '${username}'")
User findByUsername(@Param("username") String username);
```

### 3. XSS防护

```java
// ✅ 正确：输出转义
@ResponseBody
public String getUserInfo(Long userId) {
    User user = userService.getById(userId);
    return HtmlUtil.escape(user.getName());
}

// ❌ 错误：直接输出用户输入
@ResponseBody
public String getUserInfo(Long userId) {
    User user = userService.getById(userId);
    return user.getName();  // 可能包含<script>标签
}
```

### 4. 密码安全

```java
// ✅ 正确：使用BCrypt加密
@Service
public class AuthService {
    
    @Autowired
    private PasswordEncoder passwordEncoder;
    
    public void register(User user) {
        String encodedPassword = passwordEncoder.encode(user.getPassword());
        user.setPassword(encodedPassword);
        userMapper.insert(user);
    }
    
    public boolean login(String username, String password) {
        User user = userMapper.findByUsername(username);
        return passwordEncoder.matches(password, user.getPassword());
    }
}

// ❌ 错误：明文存储或使用弱哈希
user.setPassword(DigestUtils.md5Hex(password));  // MD5不安全
```

### 5. 敏感信息保护

```java
// ✅ 正确：脱敏处理
@Data
public class UserVO {
    
    @Desensitize(type = DesensitizeType.MOBILE)
    private String mobile;  // 138****1234
    
    @Desensitize(type = DesensitizeType.EMAIL)
    private String email;   // te***@example.com
    
    @JsonIgnore
    private String password;  // 不返回密码
}

// ❌ 错误：暴露敏感信息
@Data
public class UserVO {
    private String mobile;     // 完整手机号
    private String email;      // 完整邮箱
    private String password;   // 密码泄露！
}
```

## ⚡ 性能规范

### 1. 数据库优化

```java
// ✅ 正确：只查询需要的字段
@Select("SELECT id, username, email FROM users WHERE id = #{id}")
UserVO selectUserVOById(Long id);

// ❌ 错误：SELECT *
@Select("SELECT * FROM users WHERE id = #{id}")
User selectUserById(Long id);

// ✅ 正确：分页查询（Bedrock 使用 Query + PageUtil）
public R<IPage<UserVO>> page(Query query) {
    return R.success(userMapper.selectPage(PageUtil.getPage(query), wrapper));
}

// ❌ 错误：一次性加载所有数据
List<User> allUsers = userMapper.selectList(null);
```

### 2. 缓存使用

```java
// ✅ 正确：合理使用缓存
@Service
public class ProductService {
    
    @Cacheable(value = "product", key = "#id")
    public Product getProduct(Long id) {
        return productMapper.selectById(id);
    }
    
    @CacheEvict(value = "product", key = "#product.id")
    public void updateProduct(Product product) {
        productMapper.updateById(product);
    }
}

// ❌ 错误：频繁查询数据库
public Product getProduct(Long id) {
    return productMapper.selectById(id);  // 每次都查库
}
```

### 3. 集合操作

```java
// ✅ 正确：指定初始容量
Map<String, User> userMap = new HashMap<>(expectedSize);
List<User> userList = new ArrayList<>(expectedSize);

// ✅ 正确：使用Stream处理集合
List<String> names = users.stream()
    .filter(user -> user.getAge() >= 18)
    .map(User::getName)
    .collect(Collectors.toList());

// ❌ 错误：循环中多次查询数据库
for (User user : users) {
    Order order = orderMapper.selectByUserId(user.getId());  // N+1问题
}
```

### 4. 资源释放

```java
// ✅ 正确：try-with-resources自动关闭
try (InputStream is = new FileInputStream(file);
     BufferedReader reader = new BufferedReader(new InputStreamReader(is))) {
    String line = reader.readLine();
}

// ✅ 正确：手动关闭资源
Connection conn = null;
try {
    conn = dataSource.getConnection();
    // 使用连接
} finally {
    if (conn != null) {
        conn.close();
    }
}

// ❌ 错误：未关闭资源
InputStream is = new FileInputStream(file);
String content = new String(is.readAllBytes());  // 流未关闭
```

## 🏗️ 架构规范

### 1. 分层架构

```
┌─────────────────┐
│  Controller层   │ ← 接收请求、参数验证、响应封装
├─────────────────┤
│  Service层      │ ← 业务逻辑、事务管理
├─────────────────┤
│  Mapper层       │ ← 数据访问、SQL执行
├─────────────────┤
│  Database       │ ← 数据存储
└─────────────────┘
```

**职责分离**:
```java
// Controller: 只负责HTTP层处理
@RestController
@RequestMapping("/user")
@RequiredArgsConstructor
public class UserController extends BaseController {

    private final IUserService userService;

    @GetMapping("/detail")
    public R<UserVO> detail(Long id) {
        return R.success(userService.detail(id));
    }
}

// Service: 只负责业务逻辑
@Service
@RequiredArgsConstructor
public class UserServiceImpl extends BaseServiceImpl<UserMapper, User> implements IUserService {

    public UserVO detail(Long id) {
        User user = this.getById(id);
        return BeanUtil.copyProperties(user, UserVO.class);
    }
}

// Mapper: 只负责数据访问
@Mapper
public interface UserMapper extends BaseMapper<User> {
    // 自定义SQL
}
```

### 2. 异常处理

```java
// ✅ 正确：统一异常处理（boot 模块已内置 ExceptionAdviceHandler）
// 业务层抛出 ServiceException，全局处理器自动返回 R.error()
@Service
public class UserServiceImpl extends BaseServiceImpl<UserMapper, User> {
    public void deleteUser(Long id) {
        if (this.getById(id) == null) {
            throw new ServiceException("用户不存在");
        }
        this.logicRemoveById(id);
    }
}
```

### 3. 事务管理

```java
// ✅ 正确：在Service层控制事务
@Service
public class OrderService {
    
    @Transactional(rollbackFor = Exception.class)
    public void createOrder(OrderRequest request) {
        // 1. 创建订单
        Order order = createOrder(request);
        
        // 2. 扣减库存
        deductStock(request.getProductId(), request.getQuantity());
        
        // 3. 创建支付记录
        createPayment(order.getId(), request.getAmount());
    }
}

// ❌ 错误：在Controller层使用事务
@RestController
public class OrderController {
    
    @Transactional  // 不应该在这里
    @PostMapping("/orders")
    public Result<Void> createOrder(@RequestBody OrderRequest request) {
        // ...
    }
}
```

### 4. 日志规范

```java
// ✅ 正确：合理使用日志级别
@Slf4j
@Service
public class UserService {
    
    public User getUserById(Long id) {
        log.debug("查询用户, id={}", id);
        
        User user = userMapper.selectById(id);
        
        if (user == null) {
            log.warn("用户不存在, id={}", id);
            return null;
        }
        
        log.info("查询用户成功, id={}, name={}", id, user.getName());
        return user;
    }
    
    public void createUser(UserDTO userDTO) {
        try {
            // 业务逻辑
        } catch (Exception e) {
            log.error("创建用户失败, userDTO={}", userDTO, e);
            throw new BusinessException("创建用户失败");
        }
    }
}

// ❌ 错误：日志使用不当
System.out.println("user=" + user);  // 不要用System.out
log.info("user=" + user);            // 不要字符串拼接
log.error(e.getMessage());           // 要传入异常对象
```

```java
public BigDecimal calculateDiscount(Order order) {
    // VIP用户享受8折优惠
    if (order.getUser().isVip()) {
        return order.getAmount().multiply(new BigDecimal("0.8"));
    }
    
    // 满100减20
    if (order.getAmount().compareTo(new BigDecimal("100")) >= 0) {
        return order.getAmount().subtract(new BigDecimal("20"));
    }
    
    // 默认无优惠
    return order.getAmount();
}
```

## ⚠️ 禁止事项

### ❌ 严禁出现

1. **硬编码敏感信息**
   ```java
   // ❌ 禁止
   String password = "admin123";
   String apiKey = "sk-xxxxx";
   
   // ✅ 正确
   @Value("${app.password}")
   private String password;
   ```

2. **捕获异常后不做处理**
   ```java
   // ❌ 禁止
   try {
       doSomething();
   } catch (Exception e) {
       // 空catch块
   }
   
   // ✅ 正确
   try {
       doSomething();
   } catch (Exception e) {
       log.error("操作失败", e);
       throw new BusinessException("操作失败");
   }
   ```

3. **使用魔法值**
   ```java
   // ❌ 禁止
   if (user.getStatus() == 1) { }
   
   // ✅ 正确
   if (user.getStatus() == UserStatus.ACTIVE.getCode()) { }
   ```

4. **线程不安全的全局变量**
   ```java
   // ❌ 禁止
   @Component
   public class UserService {
       private SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd");
   }
   
   // ✅ 正确
   @Component
   public class UserService {
       private static final DateTimeFormatter formatter = 
           DateTimeFormatter.ofPattern("yyyy-MM-dd");
   }
   ```

✅ **命名规范** - 清晰表达意图  
✅ **代码格式** - 统一的视觉风格  
✅ **安全规范** - 防止安全漏洞  
✅ **性能规范** - 避免性能陷阱  
✅ **架构规范** - 保持层次清晰

✅ **测试规范** - 保障代码可靠性  

**最佳实践**:
1. 使用IDE插件检查代码规范（如Checkstyle、SonarLint）
2. Code Review时重点关注规范遵守情况
3. 定期组织规范培训和分享
4. 持续改进和完善规范
5. 自动化检查代替人工审查
